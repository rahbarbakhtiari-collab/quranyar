IMPLEMENTED
- Added explicit self-service Program re-application for withdrawn relationships.
- Reapply is available only while Program registration is open and the prior Application/Enrollment is withdrawn.
- Reapply returns the canonical Application to submitted; prior acceptance/enrollment is never silently restored.
- Eligibility, tenant snapshot, registration window and capacity are rechecked server-side.
- A previous withdrawn Enrollment is reactivated only after renewed acceptance + enrollment.
- Re-enrollment reuses the canonical Enrollment row and preserves Program audit / attendance history.
- Capacity semantics distinguish old acceptance before withdrawal from new acceptance after reapply using decided_at_utc > withdrawn_at_utc.
- Re-submitted applications remain withdrawable even while an old withdrawn Enrollment row exists.
- Single and bulk admin enrollment paths support accepted reapplications with withdrawn Enrollment rows.
- Member UI shows a human “ثبت‌نام مجدد” CTA with explicit confirmation and correct active Application state after reapply.
- Added Health Center Program reapply contract card.
- Added migration 20261011_041_rc53_program_reapply_after_withdrawal owned by programs.
